# Contribuindo

Antes de abrir uma alteração:

1. Leia `AGENTS.md`, `PLANO.md` e `PROGRESSO.md`.
2. Rode `uv run ruff check pipeline scripts` e `uv run pytest`.
3. Atualize a documentação diretamente relacionada.

## DCO

As contribuições devem ser assinadas no commit com `git commit -s`, confirmando
que o autor tem direito de enviar o trabalho sob a licença do projeto.

Não inclua credenciais, dados pessoais não necessários ou cópias de matérias.
